Tutorial Masang & Verifikasi UID

1

Unduh File Config

Klik tombol "UNDUH" pada menu Local Config File untuk mengunduh file secara langsung.

2

Pasang File Config

Pindahkan file localconfig.json menggunakan ZArchiver ke folder:

Android > data > com.dts.freefireth > files > ImageCache

3

Lakukan Verifikasi ID (Sebelum Login)

Buka menu "Verifikasi UID System" dan selesaikan verifikasi Game ID Free Fire Anda sebelum membuka/login ke dalam game.

4

Login ke Game Free Fire

Setelah ID terverifikasi, buka game Free Fire dan lakukan login seperti biasa. Fitur/config akan aktif secara otomatis.
